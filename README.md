# 크리스마스 프로모션

## 🚀 기능 구현 목록

### 1. 입출력 (View)
- [ ] **입력**
  - [ ] 방문 날짜 (일자 숫자만)
  - [ ] 메뉴와 개수 (메뉴-개수)
- [ ] **출력**
  - [ ] 이벤트 미리 보기
    - [ ] 날짜
    - [ ] 주문 메뉴
    - [ ] 총 주문 금액
    - [ ] 증정 메뉴
    - [ ] 혜택 내역
    - [ ] 총혜택 금액 (음수)
    - [ ] 할인 후 예상 결제 금액
    - [ ] 12월 이벤트 배지
  - [ ] 에러 메시지 출력 (`[ERROR]` 접두사 포함)

### 2. 비즈니스 로직 (Domain)
- [ ] **핵심 객체: Menu**
  - [ ] 상태값 유효성 검증 (객체 생성 시)
  - [ ] 핵심 동작 구현 (예: 전진 조건 판단)
- [ ] **부가 객체: Category**
  - [ ] 컬렉션 관리 및 비즈니스 규칙 적용
- [ ] **부가 객체: EventBadge (Enum)**
- [ ] **관리 객체: OrderService**
  - [ ] 전체 게임 흐름 제어 및 상태 업데이트
  - [ ] 우승자/결과 판별 로직

### 3. 예외 처리 (Exception)
> 모든 예외는 `IllegalArgumentException`을 발생시키며, `[ERROR]`로 시작하는 메시지를 출력한다.

  - [ ] [예외] 방문 날짜
    - [ ] 방문할 날짜는 1 이상 31 이하의 숫자
    - [ ] 1 이상 31 이하의 숫자가 아닌 경우, "[ERROR] 유효하지 않은 날짜입니다. 다시 입력해 주세요."라는 에러 메시지를 보여 줌
  - [ ] [예외] 메뉴
    - [ ] 고객이 메뉴판에 없는 메뉴를 입력하는 경우, "[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요."라는 에러 메시지
    - [ ] 메뉴의 개수는 1개 이상 / 이외의 입력값은 "[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요."라는 에러 메시지
    - [ ] 형식이 다른 경우 "[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요."라는 에러 메시지
    - [ ] 중복 메뉴를 입력한 경우(e.g. 시저샐러드-1,시저샐러드-1), "[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요."라는 에러 메시지
